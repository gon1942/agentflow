# Changelog

## 0.5.0-rc.1
- npm/npx distribution wrapper for the established v0.4.0 native-skills installer.
- Preserve verified upstream skills, project-local RTK/CRG/browser tools and the no-teamdev workflow.
- Add GitHub Actions CI, gated npm release template, offline packed-artifact tests.
- Requires Python 3.10+ at install time; Node-only installer not yet implemented.
- No GitHub repo or npm publication performed by producing this package.
