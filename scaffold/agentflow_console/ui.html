새 프로필 만들기

독립 검증·리뷰 단계는 유지합니다. 사용자 정의 프로필의 승인 단계는 생성 후 프로필 관리에서 켜거나 끌 수 있습니다.

생성만으로 현재 활성 프로필이 바뀌지는 않습니다.

프로젝트·세션별 Profile

프로젝트 기본값은 신규 TASK에만 적용됩니다. 각 OpenCode / Claude 세션에는 독립적인 기본 Profile을 지정하세요. 지원되는 네이티브 Hook이 요청을 받을 때 세션을 자동 등록하고 최신 기본 Profile을 조회합니다. 기존 TASK에는 적용되지 않습니다. Hook 미지원 호스트는 수동 확인이 필요합니다.

어떤 스킬을 추가하시나요?

기존 설치 스킬이면 스킬 트리에서 바로 연결하세요. 새 스킬이라면 아래에서 AI 추천 또는 Git·ZIP·로컬 소스를 선택하세요.

스킬은 프로젝트 내부 세 Agent 경로에만 설치합니다.

설치된 스킬 0

무결성은 설치된 파일의 해시 일치 여부입니다. 네이티브 로딩은 실행한 Agent의 별도 증거가 필요합니다.

ZIP 스킬 파일 선택해서 설치

압축파일 경로를 입력할 필요 없이 PC에서 ZIP 파일을 선택하세요. 압축파일 안에 SKILL.md가 있어야 합니다. 파일 검사 후 설치 승인 버튼이 활성화됩니다.

ZIP 파일을 선택한 후 파일 검사를 누르세요.

내 스킬 직접 만들기

외부 파일 없이 SKILL.md 하나를 안전하게 생성합니다. AI 추천 내용을 참고하여 작성할 수 있습니다. 실제 네이티브 실행은 별도 검증됩니다.

ID·설명·실행 지침을 입력한 후 미리보기를 확인하세요.

관리 스킬 제거

스킬 트리에서 연결 해제하는 것과 프로젝트에서 파일을 제거하는 것은 다른 작업입니다. 이 영역은 파일 제거 기능입니다.

기본 7종은 삭제할 수 없습니다. 다른 Tree에서 사용하는 스킬이나 사용자 수정 파일은 삭제하지 않습니다.

AI 스킬 도우미 · 검색·검토 제안 (실험적)

AI 추천은 아래에서 선택한 프로필·단계를 기준으로 합니다. 스킬 설치·연결은 별도 승인 후 진행됩니다.

대기 중
AI 추천은 설치가 아닙니다. 아래 Git/ZIP/로컬 방식으로 출처를 먼저 확인한 뒤 설치를 명시적으로 승인해야 합니다.

추천 실행 이력 및 검증

실행 ID별 검색 엔진·검색어·단계·결과를 확인합니다. 로그에는 요청 원문, 모델 원문, 인증 정보가 저장되지 않습니다.

실행 이력을 선택하면 로그가 표시됩니다.

스킬 추천 목록 · 선택 후 적용

로컬 검증 스킬은 선택 후 연결할 수 있습니다. 외부 추천은 실제 Git 소스 검사를 거쳐야 설치할 수 있습니다. 설치·배치는 자동 실행되지 않습니다.

연결 전 최종 승인이 필요하며, 실제 네이티브 스킬 로딩은 별도로 검증해야 합니다.

AI가 추천한 스킬을 설치하려면 아래 Git URL과 고정 Commit 또는 로컬 ZIP/폴더 경로를 입력해 설치 전 분석을 실행하세요. 출처 확인과 승인 후에만 설치되며, 설치 후 스킬 트리에서 연결해야 합니다. 
이 기능은 호스트 CLI가 설치·설정되어 있어야 동작합니다. 추천 결과는 실제 설치나 검증을 의미하지 않습니다.

Git 스킬 가져오기 (HTTPS 또는 file:/// / 고정 Commit)

GitHub 주소만 입력했다면 먼저 ‘최신 Commit SHA 조회’를 누르세요. 조회한 SHA를 고정한 후 소스 검사와 설치 승인을 진행합니다. GitHub 이외의 주소는 직접 40자리 Commit을 입력해야 합니다.

Git 설치 전 출처·Commit·파일 목록을 검토하세요.

Local / ZIP 가져오기

외부 스킬 소스는 코드 리뷰 후 설치하세요. LLM 추천 연동과 공개 레지스트리 검색은 별도 검증 대상이며, 설치 시 스크립트를 실행하지 않습니다.

소스를 입력하고 설치 전 분석을 실행하세요.

에이전트 구성

기존 네이티브 워커를 유지하며 단계별 스킬 트리의 담당 역할을 확인합니다. 이 화면은 설정 현황 조회용입니다.

에이전트 목록 표시가 실제 네이티브 파견 성공을 증명하지는 않습니다. 호출 증거는 실행·검증 화면과 TASK 로그에서 확인하세요.

실행 계약 및 검증

Coordinator가 새 작업 시작 시 이 계약을 조회하도록 안내됩니다. 웹 콘솔은 Workflow 엔진이 아닙니다.

실행 계약 조회는 설정 확인이며, 실제 Worker 파견 또는 네이티브 Skill 로딩 증거를 대신하지 않습니다.
